Glossar

Differentialgleichung (DGL)
Gleichung, die eine gesuchte Funktion mit ihren Ableitungen verbindet. L01
Ordnung
Höchste vorkommende Ableitung in der DGL. y″ → 2. Ordnung. L01
Allgemeine Lösung
Funktionenschar mit Konstante C, z. B. y = x² + C. L01
Spezielle Lösung
Eine einzelne Funktion aus der Schar, C ist durch eine Bedingung festgelegt. L01
Anfangsbedingung
Vorgegebener Wert wie y(0) = 3, legt C fest. Ordnung n → n Bedingungen. L01
Anfangswertaufgabe (AWA)
DGL + Anfangsbedingung. Lösung ist eine Funktion. L01
Randbedingung
Wie Anfangsbedingung, aber an verschiedenen Stellen (z. B. y(0) und y(2)). L01
Linienelement
Kurzes Strichstück im Punkt (x|y) mit der Steigung y′ aus der DGL. L03
Richtungsfeld
Alle Linienelemente zusammen. Lösungskurven laufen entlang der Striche. L03
Isokline
Menge aller Punkte mit gleicher Steigung y′. L03
Trennen der Variablen
Für y′ = f(x)·g(y): dy/g(y) = f(x)dx, integrieren, nach y auflösen. L04
direkt / indirekt proportional
direkt zu A → k·A, indirekt zu A → k/A; Abnahme → −k. L02
